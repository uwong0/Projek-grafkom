Final XAMPP-ready package — Clickable transparent images
--------------------------------------------------------
- Open http://localhost/grafkom/ after copying this folder to C:\xampp\htdocs\grafkom and starting Apache.
- Click the images in the 3D scene (or use the list) to view full descriptions on the right.
- If images appear non-transparent, clear browser cache (Ctrl+F5) and ensure files in models/ are the transparent versions.
